# Exploring_Transformers_on_Individual_Pixels_Kulapin_Melnik

**Описание:** 
Проект по глубинному обучению, целью которого является анализ статьи An Image is Worth More Than 16×16 Patches: Exploring Transformers on Individual Pixels, опубликованной на ICLR 2025. 
Целью является проверка гипотезы, о том что ViT без патчей (каждый пиксель — токен) конкурентоспособен с патчевым ViT при равном размере модели на CIFAR-100, с учетом времени и памяти(1024 токена на 32×32), а также выявление сильных и слабых сторон данной статьи.

На первом этапе будет предоставлено Ядро воспроизведения(Table 3 — pixel-вариант vs. ViT с патчами 2×2), краткое описание статьи и ее недочеты. Также будет составлен план по проекту, включающий в себя ожидания, ответственности участников и идейное представление по улучшению статьи. В конце будет предоставлена декларация по использованию LLM, в которой будет описано, как использовался искусственный инетелект для поиска информации по проекту(код, текст, анализ, поиск литературы).


**Статья:** [An Image is Worth More Than 16×16 Patches: Exploring Transformers on Individual Pixels](https://arxiv.org/pdf/2406.09415)

**Авторы:** Кулапин Егор, Мельник Георгий
